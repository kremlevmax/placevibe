# MVP scope

## First MVP
The first MVP is a public interactive historical map.

Included:
- map layout with header, sidebar, and map area;
- markers from mock data;
- marker types: battle, person, building, event, artifact;
- popup on marker click;
- sidebar details for selected marker;
- filters by marker type;
- search by title.

Not included yet:
- user accounts;
- moderation;
- database;
- file upload;
- comments;
- microservices;
- microfrontend;
- Kubernetes;
- Elasticsearch.

## Later milestones
1. Java REST API.
2. PostgreSQL storage.
3. User-submitted markers.
4. Auth and roles.
5. Moderation.
6. Search.
7. Advanced architecture labs.
